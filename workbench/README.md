# 同族答复工作台

本地运行的第一版，不调用大模型，不需要 API 密钥。输入任意法域申请号，以巴西为默认答复目标，研究同族、补充原件、默认复用参考答复与权项，导出英文 Word 文件和中文摘要。

## 启动

Windows 双击本目录的 `启动工作台.cmd`。当前 Codex 电脑会优先使用随应用提供的 Python 及文档组件。

重复双击会直接打开正在运行、使用同一案件目录的工作台，不再启动第二个服务。若端口被其他程序或另一案件目录占用，会提示使用其他端口，不会关闭现有程序。

其他电脑先安装 Python 3.10+，在仓库根目录运行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r workbench\requirements.txt
.venv\Scripts\python.exe -m workbench --open
```

macOS / Linux：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r workbench/requirements.txt
.venv/bin/python -m workbench --open
```

默认地址 `http://127.0.0.1:8765`，只允许本机访问。端口占用时加 `--port 8766`。关闭服务窗口或按 Ctrl+C 停止。案件保存在仓库根目录 `workbench-data`，可用 `--data-dir` 指定其他位置；关闭后下次可继续处理。不要将案件目录提交到公开仓库。

## 三步使用

1. **研究与材料**：输入申请号或公开号及目标法域，新建案件。系统尝试获得同族书目、公开文本及可访问的欧洲案卷目录。失败记录原因，给出手动查找入口；准确的文件名称和日期仅来自实际取得的目录。已下载文件可直接打开。
2. **选择与编辑**：补传 PDF、DOCX、UTF-8 TXT 或 MD。标明文件角色、法域、语言、日期与版本。可以指定参考答复、参考权项、本案 OA、当前待审权项及原始申请；空选择按已知规则自动选取。文字编辑和修改依据表可直接保存。适用性核查选项默认关闭，不阻止出稿。
3. **答复包**：生成英文意见陈述、修改标记页、清洁权项、修改依据表，以及中文摘要。同族报告按 Markdown 交付；ZIP 含生成文件和已取得原件。每次生成单独保存，重新生成前仍可查上次版本。

**打开虚构示例**可快速验证完整流程。示例申请号和论证均为演示数据，不对应真实案件。

## 当前实际能力

| 功能 | 第一版行为 |
|---|---|
| 任意法域输入 | 识别法域前缀；可输入申请号或公开号。无公开书目时不猜同族。可识别 US xx/xxx,xxx 与 PCT 格式，但具体站点未必接受所有编号写法 |
| 同族发现 | 解析 Google Patents 明示的同族表，排除引证和类似文献；这不是官方当前法律状态证明 |
| 公开说明书 | 从真实书目中取得 PDF 链接，验证 PDF 文件结构并保存来源及 SHA256 |
| EPO | 解析 All documents 日期/标题/文档 ID，读取真实查看器内嵌 PDF 地址；下载最近实质意见及最近答复轮次候选。限流、验证码转人工下载。尚未验证可稳定自动 ZIP 下载 |
| WIPO / INPI / USPTO | 提供官方案卷入口与补件操作。当前没有 WIPO/INPI 交互式案卷全自动解析器，也没有 USPTO 会话下载适配器。公开文本下载与完整案卷获取严格区分 |
| PDF 文字 | pypdf 提取文字及页码；扫描件保存原件并提示补充文字，不执行 OCR，不将无文字视为无意见 |
| OA 与策略 | 显式关键词和引证号提取、同族原文复用和规则候选映射；没有开放式技术理解或自动创造性判断 |
| 权项版本 | 明确指定本案 pending 版本；不将公开文本、辅助请求、未被接受的修改或外国授权文本自动当作本案当前权项 |
| 英文草案 | 原文保留，已知申请标识可确定性替换；原始文本及替换记录留存。外国法律/程序不自动等同为巴西法律 |
| 修改标记 | 精确逐词比较，保留符号；US 格式另处理 New/Canceled 等状态。缺英文底稿时明确没有本案正式比较页 |
| 修改依据 | 核对所填出处是否能在本案原始文件指定页定位；文本存在不等于已判断合法支持 |
| 期限官费 | 缺依据一律未核验。明确选择 BR 初步技术审查 90 天规则并提供 RPI 触发日与来源后计算名义日期；节假日调整及适用性仍未核验。不猜官费金额 |

首次自动检索主要验证可达性，不能保证 EPO/WIPO/INPI 在所有网络均可直连。手动补件是同一流程的正常入口，不需要重建案件。最新 OA 尚未有答复时，最近一次已答复轮次单独显示为候选配对。

## 开发与验证

```powershell
python -m unittest discover -s workbench/tests -v
python scripts/package_skill.py --check
```

运行测试需要 requirements.txt 的文档依赖。测试使用独立临时案例，并不对真实案件推断授权/答复结果。`workbench-data/test-runs` 是可独立清理的测试输出。

`storage.py` 管数据与原件；`retrieval.py` 管公开站点访问与解析；`research.py` 管取卷流程；`analysis.py` 管证据选择和规则；`drafting.py` 管交付；`server.py` 管本机接口；`static` 是无构建依赖的网页。

本应用与仓库原有 `SKILL.md` 独立。根目录 skill 安装/发布版本仍是 0.2.1；工作台初版为 0.1.0。工作台尚不随 `.skill` 安装包分发，使用完整仓库运行。不会自动递交申请、缴费、发送邮件或上传案卷。
