# 同族答复工作台

本地运行的第一版，不调用大模型，不需要 API 密钥。输入任意法域申请号，以巴西为默认答复目标，研究同族、补充原件、默认复用参考答复与权项，导出英文 Word 文件和中文摘要。

## 启动

Windows 双击本目录的 `启动工作台.cmd`。当前 Codex 电脑会优先使用随应用提供的 Python 及文档组件。

重复双击会直接打开正在运行、使用同一案件目录的工作台，不再启动第二个服务。若端口被其他程序或另一案件目录占用，会提示使用其他端口，不会关闭现有程序。

其他电脑先安装 Python 3.10+，在仓库根目录运行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r workbench\requirements.txt
.venv\Scripts\python.exe -m workbench --open
```

macOS / Linux：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r workbench/requirements.txt
.venv/bin/python -m workbench --open
```

默认地址 `http://127.0.0.1:8765`，只允许本机访问。端口占用时加 `--port 8766`。关闭服务窗口或按 Ctrl+C 停止。案件保存在仓库根目录 `workbench-data`，可用 `--data-dir` 指定其他位置；关闭后下次可继续处理。不要将案件目录提交到公开仓库。

### 可选：欧洲案卷整包自动下载

register.epo.org 部署了 Cloudflare 人机验证，对数据中心 IP 直接返回 403，纯 HTTP 客户端无法取卷。安装可选组件后，直连失败时工作台会打开一个**可见的** Chromium 窗口，自动通过（或请你点一次）人机验证，全选目录文件并以 ZIP 整包下载：

```sh
pip install playwright
python -m playwright install chromium   # 系统已有 Chrome/Chromium 时可跳过
```

- 有图形界面的电脑默认有头模式；首次运行若弹出验证窗口，完成一次即可（最长等待 10 分钟）。
- 无显示环境自动使用无头模式；可用 `WORKBENCH_EP_HEADLESS=1` 强制。
- 走代理网络时读取 `HTTPS_PROXY` 等标准环境变量。
- 用 `WORKBENCH_EP_BROWSER=0` 可完全关闭浏览器回退（例如自动化测试）。
- 整包按“日期 + 标题”对应目录条目后逐件导入；对不上的文件保留 ZIP 原件并记入日志，不静默丢弃。

## 三步使用

1. **研究与材料**：输入申请号或公开号及目标法域，新建案件。系统尝试获得同族书目、公开文本及可访问的欧洲案卷目录。失败记录原因，给出手动查找入口；准确的文件名称和日期仅来自实际取得的目录。已下载文件可直接打开。
2. **选择与编辑**：补传 PDF、DOCX、UTF-8 TXT 或 MD。标明文件角色、法域、语言、日期与版本。可以指定参考答复、参考权项、本案 OA、当前待审权项及原始申请；空选择按已知规则自动选取。文字编辑和修改依据表可直接保存。适用性核查选项默认关闭，不阻止出稿。
3. **答复包**：按固定编号交付——00 完整答复包 ZIP、01 同族审查历史报告、02 同族原件与目录说明 ZIP（研究取得的同族 OA/答复/权项原件加目录表）、03 英文意见陈述书、04 权利要求修改标记页、05 修改后清洁稿、06 修改依据表（MD/CSV）、07 中文摘要、08 补充材料指南、09 来源记录。每次生成单独保存，重新生成前仍可查上次版本。

进入“答复包”即在工作台内显示英文意见陈述书。通过“预览文件”切换修改标记页、清洁稿、修改依据表、中文摘要、同族历史和来源记录；“下载当前文件”保留原始格式，“全部文件与其他格式”提供其他下载入口。已有答复包也可直接预览，无需重新生成。

Word 正文预览使用同一批生成的 HTML，保留删除线和新增下划线；最终分页以下载的 Word 为准。若旧文件缺少配套 HTML，会提示重新生成，仍可下载原 Word。预览只读取本次导出，不修改原件或草案。

**打开虚构示例**可快速验证完整流程。示例申请号和论证均为演示数据，不对应真实案件。

## 当前实际能力

| 功能 | 第一版行为 |
|---|---|
| 任意法域输入 | 识别法域前缀；可输入申请号或公开号。号码直达页失败时查询对应公开号，最多核验三个候选，并用书目中的申请号/公开号确认身份后再研究同族。无精确对应的公开书目时显示失败原因，不将相似结果当作同族。可识别 US xx/xxx,xxx 与 PCT 格式，但具体站点未必接受所有编号写法 |
| 同族发现 | 解析 Google Patents 明示的同族表，排除引证和类似文献；这不是官方当前法律状态证明 |
| 公开说明书 | 从真实书目中取得 PDF 链接，验证 PDF 文件结构并保存来源及 SHA256 |
| EPO | 解析 All documents 日期/标题/文档 ID，读取真实查看器内嵌 PDF 地址；下载最近实质意见及最近答复轮次候选。直连失败时回退到真实浏览器整包 ZIP 下载（可选组件，见下）；仍失败则转人工下载指引 |
| WIPO / INPI / USPTO | 提供官方案卷入口与补件操作。当前没有 WIPO/INPI 交互式案卷全自动解析器，也没有 USPTO 会话下载适配器。公开文本下载与完整案卷获取严格区分 |
| PDF 文字 | 逐页提取原生文字；扫描页使用本地 RapidOCR。保留原 PDF、原页码和置信度提示，缓存识别结果；空白、失败和低置信度页面明示，不将识别失败视为没有审查意见 |
| OA 与策略 | 显式关键词和引证号提取、同族原文复用和规则候选映射；没有开放式技术理解或自动创造性判断 |
| 权项版本 | 明确指定本案 pending 版本；不将公开文本、辅助请求、未被接受的修改或外国授权文本自动当作本案当前权项 |
| 英文草案 | 原文保留，已知申请标识可确定性替换；原始文本及替换记录留存。外国法律/程序不自动等同为巴西法律 |
| 修改标记 | 精确逐词比较，保留符号；US 格式另处理 New/Canceled 等状态。缺英文底稿时明确没有本案正式比较页 |
| 修改依据 | 核对所填出处是否能在本案原始文件指定页定位；文本存在不等于已判断合法支持 |
| 期限官费 | 缺依据一律未核验。明确选择 BR 初步技术审查 90 天规则并提供 RPI 触发日与来源后计算名义日期；节假日调整及适用性仍未核验。不猜官费金额 |

首次自动检索主要验证可达性，不能保证 EPO/WIPO/INPI 在所有网络均可直连。手动补件是同一流程的正常入口，不需要重建案件。最新 OA 尚未有答复时，最近一次已答复轮次单独显示为候选配对。

## 本地 OCR

在工作台使用的 Python 环境中安装：

```powershell
.venv\Scripts\python.exe -m pip install -r workbench\requirements-ocr.txt
```

重启工作台后，研究下载结束、导入 PDF、生成答复包前都会处理未识别的 PDF。已有案件在“研究与材料 → 案件材料”点击“识别扫描材料”补做；不必重新下载欧洲 ZIP。后台显示当前文件和页码，可先查看已完成文件。

“详情”按原 PDF 页码显示提取/OCR 文字，提供“下载分页文字 TXT”；完整答复 ZIP 包含 `extracted-text/` 派生文字。结果和行坐标缓存于 `workbench-data/.ocr-cache`，以原件 SHA256、引擎版本、渲染配置和页码区分，已有成功结果不重复识别。原始 PDF 不增加文字层、不覆盖、不重压缩。

使用 [RapidOCR](https://github.com/RapidAI/RapidOCR) 的 CPU 本地模型和 [PDFium Python 绑定](https://pypi.org/project/pypdfium2/) 渲染，不调用大模型或远程文档识别服务。安装依赖需联网，识别使用包内模型。单文件上限 500 页；按页处理图像并限制渲染像素。数百页扫描案卷首次处理耗时较长。

识别优先按正向读取，低置信度行才尝试方向纠正并保留前后读数，避免方向分类器把正常英文长行误转 180°。旧版缓存可复用文字框和可靠行，仅补做低置信度行；新旧缓存分开保存。

识别结束后（包括全部命中缓存时），系统补全来源选择所需的元数据：仅在正文英文词汇充分且主要为拉丁字母时将未知语言推断为英文，并在来源记录保留推断方法；不靠英文标题判断法文、德文或中文正文。欧洲案卷中同申请、同日提交的答复与清洁权项建立候选轮次对应，权项记为参考版本。ZIP 下载和单件下载走相同的关联规则，已有案件重新生成即可补全，无需重新检索。

置信度是引擎输出的行级指标，不是技术或法律正确率。存在低置信度行、无文字或失败页时，材料详情和重新生成的草案缺口都会提示核对；缓存保留成功页，失败页重试。语言推断和日期配对不代表已被审查员接受，也不把同族权项升级为本案 pending。用户明确编辑的语言、角色、版本及轮次不自动覆盖；带批注/修订的权项继续保留其清洁文本限制。

未装 OCR 组件时仍可运行工作台、保存和下载原件；扫描页提示安装组件后重试或补充文字。

## 开发与验证

```powershell
python -m unittest discover -s workbench/tests -v
python scripts/package_skill.py --check
```

运行测试需要 requirements.txt 的文档依赖。测试使用独立临时案例，并不对真实案件推断授权/答复结果。`workbench-data/test-runs` 是可独立清理的测试输出。

`storage.py` 管数据与原件；`retrieval.py` 管公开站点访问与解析；`research.py` 管取卷流程；`ocr.py` 管页级识别与缓存；`metadata.py` 管可追溯的正文语言推断和候选轮次关联；`analysis.py` 管证据选择和规则；`drafting.py` 管交付；`preview.py` 管已有交付的只读预览；`server.py` 管本机接口；`static` 是无构建依赖的网页。

本应用与仓库原有 `SKILL.md` 独立。根目录 skill 安装/发布版本仍是 0.2.1；工作台初版为 0.1.0。工作台尚不随 `.skill` 安装包分发，使用完整仓库运行。不会自动递交申请、缴费、发送邮件或上传案卷。
