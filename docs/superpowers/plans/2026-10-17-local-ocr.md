# Local OCR implementation plan

Goal: Add automatic, local page-level OCR to downloaded/imported scans and reprocess the existing European dossier without changing original PDFs or source metadata.

Approved scope: the user's confirmed detection → OCR → source/page retention → quality checks workflow. Execute inline; preserve the current workbench UI and source/version safeguards.

Architecture: `ocr.py` owns native-text detection, PDFium rendering, RapidOCR CPU inference and content-addressed page caches. Store applies derived results and invalidates old exports. Existing background jobs run OCR after research/import and before generation; a case action backfills existing material. Language, role, version and marked-source restrictions remain explicit metadata.

- [x] Write regression tests for mixed native/scanned PDFs, original bytes, page identity, cache reuse/invalidation, per-page failures, low confidence, and missing components.
- [x] Implement a bounded local OCR engine and per-page cache. Keep successful pages when another page fails; retain native text and document hashes.
- [x] Integrate Store processing and background HTTP jobs, automatic import/research/generation hooks, text export and OCR provenance in packages.
- [x] Add the case OCR action, progress/status and page-labelled material preview using existing styles.
- [x] Install project OCR dependencies, test actual EPO opinion/reply/claims, verify cache reuse and original integrity; start the remaining dossier backfill in the persistent local service.
- [x] Run appropriate automated checks, one desktop/mobile UI inspection and one confirmation round, document evidence and commit the completed changes.

Acceptance: 94 automated tests and the original skill packaging check pass. Key opinion/reply/clean claims each produced four correctly numbered OCR pages and preserved original hashes. A four-page cache reread bypassed inference and retained identical text. The remaining full-dossier batch continues in the local service; processing progress is visible and is not represented as completed.

Limits: OCR confidence measures recognition output, not legal or technical correctness. Do not silently clean tracked amendments, infer English language or current pending status, or use foreign text as target original support. Failed/empty pages stay explicit and can be retried. Runtime models and case data remain outside Git.
