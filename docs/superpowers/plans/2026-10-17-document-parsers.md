# 实施计划：英文案卷解析

1. 安装与实测准备：在 `workbench-data/tools` 建立独立 Docling、Paddle 环境；安装 Tesseract 英文 best 模型；核对官方 API 和输出结构。原工作台环境保持原样。
2. 测试先行：新增解析器调度、配置隔离、缓存命中、失败保留旧文字、原件完整性、布局清理及起草正文选用的回归检查，先确认失败。
3. 接入：新增解析器/子进程 worker 与布局标准化模块；`ocr.py` 保持旧调用兼容并路由可选引擎；`storage.py` 按英文关键材料选择引擎、归档派生结果；`analysis.py` 选用有来源的正文。
4. 工作台：新增解析器选择、安装情况和正文/原识别文字查看；服务端校验设置，保持现有生成入口。
5. 对测：对三份真实欧洲文件保存各引擎独立输出、原 PDF 页图和对照报告；以人工核对片段及结构完整性记录结果，不能把自动检查或置信度写成整批准确率。
6. 验收：运行全套测试、原 skill 打包和前端语法检查；请独立审查员审查本轮改动；修复实质问题；安全重启空闲工作台，验证真实生成、预览、原件与下载，再保存本地提交和使用说明。
