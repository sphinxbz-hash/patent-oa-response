# 可切换的英文案卷解析

用户已同意引入 Docling + Tesseract，并与 PaddleOCR PP-StructureV3、现有 RapidOCR 对测。沿用本地系统，标准解析不调用生成式大模型或上传案卷。

- 在案件中选择英文关键材料解析器。支持 RapidOCR、Docling/Tesseract 和 PP-StructureV3；未安装组件必须说明原因，不静默冒充成功。非英文材料继续使用原多语种流程。
- Docling/Paddle 采用独立 Python 环境与子进程，避免与运行中的工作台依赖冲突。下载官方依赖和模型，缓存置于本地忽略目录。
- 保留原 PDF、SHA256、旧识别缓存以及切换前派生文字。缓存按文件、引擎、版本、配置隔离。失败保留已有文字并标识，不用空结果替换。
- 输出逐页原识别文字、正文文字、结构块坐标、排除的页眉页脚/边栏行号及理由。正文清理不得删除权项编号、技术数字、否定词和比较符号。草案使用结构化正文，原识别文字可核查。
- 选用真实欧洲检索意见、2025-05-09 答复和清洁权项进行对测。按源 PDF 核对代表性正文、阅读顺序、漏行、1–5 项完整性、数字及引证号；记录运行时间和错误，不跨引擎比较置信度作为准确率。
- 测试通过后在本机接入工作台、重启并实际生成和预览。依据对测证据选择默认引擎；若证据不足，保持原默认并明确报告原因。缺失的巴西本案材料仍为缺口。

本轮不重做取卷、法律策略或答复格式，也不推送专利材料到外部服务。
